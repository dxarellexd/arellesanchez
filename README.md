# Arelle M. Sanchez: Portfolio

React + Vite single-page portfolio. All content lives in `src/data.js`.

## Run locally
    npm install
    npm run dev

## Build
    npm run build      # outputs to /dist

## Deploy
- **Vercel / Netlify:** push to GitHub, import the repo. Build command `npm run build`, output directory `dist`.
- **GitHub Pages:** run `npm run build`, then publish the `dist` folder (for example with the `gh-pages` package or a Pages workflow).

## Update your resume
Replace `public/Arelle_Sanchez_Resume.pdf` with a newer file of the same name.
